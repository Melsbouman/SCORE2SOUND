# Woordenlijst

De muziektermen in SCORE2SOUND, met de term uit MusicXML. Gebruik in teksten van de app altijd het woord uit de eerste kolom.

| In de app | In MusicXML | Betekenis |
|---|---|---|
| partituur | score | alle partijen van een muziekstuk samen |
| partij | part | de muziek van één instrument of stem |
| maat | measure | het stuk muziek tussen twee maatstrepen |
| opmaat | measure implicit | een onvolledige eerste maat |
| maatsoort | time | het aantal tellen in een maat, zoals 4/4 of 6/8 |
| toonsoort | key | de kruisen of mollen aan het begin van de notenbalk |
| voorteken | accidental | een kruis, mol of herstellingsteken bij een noot |
| sleutel | clef | vioolsleutel, bassleutel of een andere sleutel |
| notenbalk | staff | de vijf lijnen waarop de noten staan |
| stem | voice | een melodielijn binnen één partij |
| overbinding | tie | twee noten van dezelfde hoogte als één lange noot gespeeld |
| legatoboog | slur | noten die gebonden worden gespeeld |
| dynamiek | dynamics | hoe hard of zacht, zoals p, mf of ff |
| articulatie | articulation | hoe een noot begint of eindigt, zoals staccato of accent |
| herhaling | repeat | een stuk dat nog een keer wordt gespeeld |
| tempo | tempo | de snelheid, in kwartnoten per minuut |
| stemming | transposition | waarin een instrument klinkt, zoals in Bes of in Es |
| genoteerd | written | de noot zoals hij op het blad staat |
| klinkend | sounding | de noot zoals hij werkelijk klinkt |
| melding | (geen) | wat de app laat zien als er iets niet lijkt te kloppen |
